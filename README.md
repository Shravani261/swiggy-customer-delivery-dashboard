# Swiggy Food Delivery Analytics Dashboard (Excel)

Excel dashboards analysing food delivery data: customers, deliveries, restaurants and business performance, built with a star-schema data model, PivotTables and VBA macros.

## Dashboards
- **Home Dashboard:** navigation page for all dashboards
- **Business Overview:** orders and revenue by region and city, monthly trends, delivery status and payment modes
- **Customer Behaviour Analysis:** customers by city and order frequency
- **Delivery Performance:** delivery status, delivery time and rider performance
- **Restaurant and Food Analysis:** menu items, cuisines, ratings and price range

## Data Model
Star schema with fact tables (Orders, Order Items, Financials, Payment) and dimension tables (Customer, City, Date, Restaurant, Menu, Delivery Partner, Payment Mode, Service).

## Tools
Excel, PivotTables and PivotCharts, slicers, Power Pivot, VBA macros, dashboard design.
